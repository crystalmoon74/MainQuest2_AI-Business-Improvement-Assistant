# 구매요청 처리 표준 운영 절차(SOP) — 가상 예시

> 이 문서는 PoC 시연을 위해 만든 가상 문서입니다. 실제 회사의 절차가 아닙니다.

- 문서번호: SOP-PUR-001 / 개정일: 2025-03-01 / 주관부서: 구매팀

## 1. 목적
사내 물품·용역 구매요청을 일관된 절차로 접수·승인·발주하여 구매 통제와 처리 속도를 확보한다.

## 2. 적용 범위
전 부서의 일반 구매(사무용품, IT 장비, 소프트웨어, 외부 용역). 공사·자산 취득은 별도 규정을 따른다.

## 3. 처리 절차
1. 요청부서 담당자는 그룹웨어 전자결재의 '구매요청서' 양식으로 요청한다.
2. 요청부서장이 1차 승인한다.
3. 구매팀 담당자는 접수 후 2영업일 이내에 품목, 수량, 예산 코드를 검토한다.
4. 금액에 따라 「구매 전결 규정」의 승인권자가 최종 승인한다.
5. 구매팀은 최종 승인 후 3영업일 이내에 발주하고 요청자에게 발주 결과를 통보한다.
6. 구매팀은 매월 말 구매요청 처리 현황을 재무팀에 보고한다.

## 4. 예외 처리
- 긴급 구매: 요청부서장이 사유서를 첨부하면 구매팀장 승인으로 선발주 후 사후 결재할 수 있다.
- 반려: 반려 시 사유를 전자결재에 기록하고 요청자는 보완 후 재상신한다.

## 5. 기록 관리
구매요청서와 승인 이력은 전자결재 시스템에 5년간 보관한다.
